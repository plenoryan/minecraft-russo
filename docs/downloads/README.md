# Minecraft Russo: SayIt Modpack - Downloads

O arquivo principal de instalador portátil `Minecraft_Russo_Client_Setup.zip` é empacotado via script `package_client.ps1`.
Quando hospedado no GitHub Pages / GitHub Releases, o download direto é servido a partir deste diretório ou via link da release oficial.

- Arquivo: `Minecraft_Russo_Client_Setup.zip`
- Formato: Arquivo ZIP com cliente portátil completo (UltimMC + OpenJDK 17 + SayIt + 43 Mods Fabric 1.20.1 + Modelo Vosk Offline)
- Instrução: Extrair em qualquer pasta e executar `Jogar.bat`.
